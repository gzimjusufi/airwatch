    🔄 Data Flow

    1. Sensing (every 15s)
    ESP32 polls all 5 sensors via I²C, UART and ADC
    2. Local display
    Values shown instantly on OLED screen
    3. Cloud upload
    HTTP POST to ThingSpeak with all 6 field values
    4. Web fetch (every 30s)
    Dashboard pulls last 30 readings from ThingSpeak REST API
    5. AI analysis
    User asks chatbot → /api/chat → Groq → answer with live context

    📡 Communication Protocols

    I²C (Inter-Integrated Circuit)
    AHT20, BMP280, SCD40, OLED — 2 wires, multiple devices
    UART (Serial)
    PMS5003 — TX/RX at 9600 baud
    ADC (Analog-to-Digital)
    MAX4466 microphone — analog signal on GPIO34
    HTTP / REST
    ESP32 → ThingSpeak upload + Dashboard → ThingSpeak fetch
    HTTPS / JSON
    Dashboard → /api/chat → Groq AI API
    Wi-Fi IEEE 802.11
    ESP32 connects to local network for cloud upload

    🔐 Security Architecture

    ThingSpeak Read API Key
    Public channel — read key is acceptable to expose in frontend for this use case
    Groq API Key — server-side only
    Stored as Vercel environment variable. Browser never sees it. All AI requests proxied through /api/chat serverless function.
    No user data stored
    Dashboard is stateless — no login, no database, no personal data collected

    AirWatch

    A real-time IoT air quality monitoring system built with ESP32, multiple environmental sensors, and ThingSpeak cloud integration.

    🔧 Hardware Components

    ESP32 CP2102 Type-C
    Main microcontroller — Wi-Fi, Bluetooth, 32-bit dual-core
    AHT20 + BMP280
    Temperature, humidity & atmospheric pressure (I²C)
    SCD40
    Photoacoustic CO₂ sensor — 400–2000 ppm (I²C)
    PMS5003
    Laser PM2.5 / PM10 particulate sensor (UART)
    MAX4466
    Electret microphone amplifier — ambient sound level
    OLED 0.96″ Display
    Real-time readings on-device (I²C, SSD1306)

    ☁️ System Architecture

    Data Collection
    ESP32 reads all 6 sensors every 15 seconds
    Local Display
    OLED shows live readings instantly on-device
    Cloud Upload
    Data pushed to ThingSpeak via HTTP over Wi-Fi
    Web Dashboard
    This site — pulls ThingSpeak API, refreshes every 30s
    AI Assistant
    Groq AI analyses live data and answers questions

    📊 Health Reference Ranges

    Temperature
    Comfortable: 16–26°C
    Humidity
    Comfortable: 30–60%
    CO₂
    Good: <600 ppm · Poor: >1000 ppm
    PM2.5
    Good: ≤12 µg/m³ · Unhealthy: >55 µg/m³
    Sound
    Quiet: <40 dB · Loud: >70 dB
